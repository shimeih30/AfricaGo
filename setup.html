AFRICAGO CLOUD

One-time setup

This connects the tracker to a private Supabase database. No service-role or secret database key belongs in the browser app.

1

Create a Supabase project

Use one company-controlled account. Keep at least two founders able to recover the account.

2

Run the database SQL

Open Supabase SQL Editor and run supabase/setup.sql from this package. It creates the workspace, task, member, activity and security policies.

3

Generate the browser configuration

Copy the Project URL and the publishable key from Supabase Project Settings → API. Paste them below.

Never paste the secret key or service-role key here. The publishable browser key is protected by the Row Level Security policies created by the SQL file.
Download setup SQL

Replace the existing config.js in the app folder with the downloaded file, then upload the complete folder to any HTTPS static host. This configuration remains part of the deployed app even when a cleanup utility clears browser data.
